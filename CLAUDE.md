# WinIt — California Court Case Tracker

Source of truth for requirements: [docs/challenge-brief.md](docs/challenge-brief.md).
User stories (one file per epic): [docs/user-stories/](docs/user-stories/).

## Mandatory workflow

For EVERY request involving code, a feature or a modification, follow the
`user-story-traceability` skill in [.claude/skills/user-story-traceability/SKILL.md](.claude/skills/user-story-traceability/SKILL.md)
BEFORE writing code: find the matching user story, get the user's validation to
create/amend it, and log the change in the epic's history. Stories are never deleted.
